# Architecture decision records

This folder holds one record per design decision, named
`YYYY-MM-DD-<slug>.md`. They are written with the Agrippa planning
methodology, whose rules for when a record is required and what it contains
ship with the `agrippa` Claude Code plugin in its `design-first` skill:
[Agrippa](https://github.com/pxd5295/Agrippa).
