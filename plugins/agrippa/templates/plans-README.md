# Plans

This folder holds plan workspaces, one `YYYY-MM-DD-<name>/` folder per planned
change, and short session handoffs named `handoff-YYYY-MM-DD-<slug>.md`. They
are written with the Agrippa planning methodology, whose rules for these files
ship with the `agrippa` Claude Code plugin in its `plan` skill:
[Agrippa](https://github.com/pxd5295/Agrippa).
